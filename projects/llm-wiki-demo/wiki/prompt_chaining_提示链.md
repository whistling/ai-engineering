# Prompt Chaining (提示链)

### Core Mechanism
Prompt Chaining breaks down a complex task into sequential steps, where the output of one prompt becomes the input for the next. This reduces cognitive load per step, allows intermediate validation, and enables the use of cheaper models for simpler sub-tasks.
